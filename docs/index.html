ABOUT THE PROJECT

A reinforcement learning agent that learns to play Donkey Kong (NES) entirely by itself. It uses PPO (Proximal Policy Optimisation) and a convolutional neural network to watch the game screen and decide which buttons to press — no human gameplay data, no hard-coded rules.

The AI's decisions are mirrored in real time by a pair of simulated KUKA IIWA robot arms inside a PyBullet physics environment: one grips a joystick, the other presses a jump button on a virtual arcade cabinet — complete with coin insertion, a GAME OVER restart loop, and the actual game rendered on the cabinet screen.

HOW IT WORKS

THE AI

The agent receives a stack of preprocessed game frames (greyscale + sprite channels) and outputs one of 8 discrete actions every decision step. A reward function encourages climbing higher, dodging barrels, and reaching Pauline at the top.

TRAINING

PPO runs across multiple parallel NES emulators (via stable-retro), collecting rollouts and updating the CNN policy. Platform checkpoints let the agent drill individual transitions (curriculum learning). 10M+ timesteps are recommended for consistent climbing.

ROBOT ARMS

Two KUKA IIWA 7-DOF arms share a PyBullet physics world with a virtual arcade cabinet. Each AI action maps to a physical movement in real time:

KEY FEATURES

  • Parallel-jaw grippers with animated open/close on both arms
  • Autonomous coin-start loop — robot re-inserts a coin on GAME OVER
  • Low-pass filtered joystick (no jitter from policy sampling noise)
  • Real-time pacing synced to true NES frame rate
  • Live game feed rendered on the arcade cabinet screen (256×224)

SETUP INSTRUCTIONS

1. INSTALL WSL2

Open PowerShell as Administrator and run:

wsl --install

Restart your PC, then create a Linux username and password when Ubuntu opens.

2. INSTALL PYTHON

sudo apt update
sudo apt install python3 python3-pip python3-venv -y

3. CLONE THE REPO

cd ~
git clone https://github.com/abaeljoseph/Donkey-Kong-AI.git
cd Donkey-Kong-AI
git checkout Donkey-Kong-with-Robotics

4. SET UP VIRTUAL ENVIRONMENT

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

5. GET THE ROM

Obtain a Donkey Kong.nes ROM file (not included — copyright) and copy it into the project folder, then register it: 

python setup_rom.py

6. TRAIN THE AI

# Headless (fastest)
python main.py --algo ppo --timesteps 10000000 --num-envs 8

# With game window
python main.py --algo ppo --timesteps 10000000 --num-envs 8 --render

7. WATCH IT PLAY

# With robot arms + game window (NO GPU)
python main.py --algo ppo --eval-only \
  --load-model previous_archive/ppo59a_20m \
  --num-envs 1 --arm-gui --arm-renderer software --render
